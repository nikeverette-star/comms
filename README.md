# comms

A collection of small Python data-visualization projects. Each project lives in
its own folder with its own README, examples, and code.

## Projects

### 📊 [matplotlib-viz](matplotlib-viz/)

A tiny matplotlib visualization library (under 200 lines) for **pandas
DataFrames**, with modern, minimal aesthetics and a **colorblind-safe** palette
that works in both light and dark modes.

→ See [`matplotlib-viz/README.md`](matplotlib-viz/README.md)

### 🎨 [color-vocabulary-viz](color-vocabulary-viz/)

A dependency-free visualization library built from the **xkcd Color Survey**
(954 crowd-sourced color names). It shows how human color vocabulary clumps
around a few favorite hues instead of spreading evenly across the spectrum.

→ See [`color-vocabulary-viz/README.md`](color-vocabulary-viz/README.md)
